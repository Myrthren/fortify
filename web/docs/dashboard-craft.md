# Dashboard and navigation refinement

This pass extends Fortify's existing graphite/silver visual system. Classic retains its site typography and softer corners; Sci-fi retains Chakra Petch display headings, tighter corners and the existing ambient signal graphic. No marketing identity, subscription permissions, provider configuration or data schema changes are introduced.

## Dashboard

The authenticated dashboard still loads the signed-in user's record and `getWorkspaceSnapshot(userId)` on the server. `DashboardHome` is the shared presentation used by the actual route and the isolated local preview.

The leading action uses real due work first, then an accessible saved content workspace, then an unfinished goal step, then a real recent activity. An empty workspace receives a free content-draft entry point. It preserves record-specific URLs and never fabricates tasks or progress. Goal changes update the displayed priority after a successful save.

Saved content workspaces have their own compact list. The activity timeline, metrics, follow-ups, failed-workflow warnings, focus guide, Discord setup and plan information remain available. The full directory retains the central tool registry, community destinations, plan labels and unavailable markers. It supports local filtering and category selection; unavailable tools are not presented as clickable actions. Existing `#toolkit` and `#hook-generator` anchors reveal the directory.

Activity refresh remains once per minute, on focus/visibility and through an explicit refresh button. A failed refresh retains the last loaded snapshot and shows an error state; a subsequent successful refresh clears it. No additional background AI requests or automated workflow runs are added.

## Navigation

The header remains server-rendered, including the owner-only Admin link and the existing sign-out server action. `NavigationDisclosure` is a small client boundary around the existing navigation destinations. Desktop menus open by click or Arrow Down; Escape restores trigger focus, outside clicks dismiss, and opening another menu closes the first. Hidden links are not left in the tab sequence. Mobile navigation scrolls within the viewport, restores page scrolling when dismissed or resized, and closes on navigation.

Search and shortcuts are available in both themes. Content now opens Story Forge rather than Brand Voice Studio, and the active Content state includes the story route. Simulation Lab has an explicit shortcut. Search supports Ctrl/Command K, input/result arrow navigation, Escape and empty results. Notifications use the existing real unread-count endpoint. The skip link targets the current page's main content.

## Review and checks

`npm run test:dashboard` covers the priority rules and record URLs. Existing workspace and universal-theme tests cover account isolation, persistent preferences, error recovery and owner permissions. Browser verification uses a fresh, isolated profile against the local preview and checks menus, keyboard interaction, search, directory filtering, refresh failure/recovery, goal selection and responsive layouts in both themes.

The preview is generated by `../../scripts/render-dashboard-craft.cjs` and served by `../../scripts/serve-dashboard-craft.cjs` at port 8459. It uses actual UI components with clearly labelled fictional records and local API doubles. Links to other workspaces show a labelled navigation destination rather than pretending to load real account data. Preview fixtures, shims and screenshots are outside the web application. Production database/provider behaviour is not verified by this preview.
