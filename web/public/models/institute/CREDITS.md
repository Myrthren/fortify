# Fortify institute head assets

Anatomical head/neck topology, adult head variation targets, blink targets, eye geometry and iris texture derive from MakeHuman Community core assets, released under CC0 1.0. Source: https://github.com/makehumancommunity/makehuman/tree/a8bc2d54ff0ac92e78ff71431b1023eda42bf482
License: https://www.makehumancommunity.org/about/license.html

Only cropped head/neck geometry is included in the application. Fortify's builder blends adult head targets, applies six small shape variations, quantizes geometry and retains eyelid closure deltas. Clothing, hair surfaces and rig integration are authored for this project. No MakeHuman application code is included.
